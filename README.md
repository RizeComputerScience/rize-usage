# Rize usage counter

The shared, privacy-safe page counter for Rize course pages hosted outside Learn. No cookies, nothing stored, no identifiers; one beacon per event to Rize's GA4 property.

Add before </body>:

    <script src="https://rizecomputerscience.github.io/rize-usage/rize-usage.js" defer></script>

Source of truth, tests and the ID instructions: rizeedu/pillars-fast-mode, scripts/usage-tracker/ and skills/usage-tracking/. Edit there, then copy rize-usage.js here.
